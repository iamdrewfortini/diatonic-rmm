# Security

Do not submit credentials, provider keys, private vault references, production inventories or personal media in public issues. Report a suspected vulnerability privately through Drew Fortini's GitHub profile contact channels. Do not exploit a live system to demonstrate an issue.

The showcase runs locally in the browser. Native SDK/RMM deployments require independently provisioned authentication, TLS and explicit authorization. A demo, configuration flag or model output cannot supply those authorities. Production credentials are not part of this repository or its CI.
